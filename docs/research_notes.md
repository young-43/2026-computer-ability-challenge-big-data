# 研究过程与经验

## 研究起点

单独使用全图可以看到整体眼底结构，局部视盘区域则提供更集中的判别信息。本项目将二者分别建模，再以固定权重融合。定位器用于减少局部输入位置的不确定性。

## 探索过的方向

| 方向 | 研究问题 | 经验 |
|---|---|---|
| 全图与局部融合 | 两种输入是否提供互补排序信息？ | 应观察配对错误及整体排名变化，单模型分数不足以判断融合收益 |
| 局部视野与亮度 | 改变输入能否帮助困难阳性？ | 局部数值变化不能直接解释为稳定收益，输入改变还可能增加推理成本 |
| 年龄辅助 | 年龄能否为视觉错误提供相反且正确的排序？ | 年龄单独有预测力，不代表它对视觉模型具有增量价值 |
| 配对排序损失 | 训练目标与 AUROC 是否一致？ | 自然批次中的阳性数量、空配对比例和梯度量级必须一起检查 |
| 阳性表征强化 | 辅助表示学习能否改善困难阳性？ | 需要同初始化、数据顺序和预算的对照，不能把采样变化误认为损失收益 |
| 轻量阳性专家 | 不同训练分布下的小模型是否互补？ | 专家自身 AUROC、错误方向互补和融合净收益是三个不同问题 |
| 原型与门控融合 | 仅在特定条件使用补充信息是否更有效？ | 单图分类冲突不等同于正负配对排序冲突，门控也会改变跨组排序 |

这些探索没有提供足够稳定的证据替代最终全图与局部固定融合方案。不能据此断言相应方法普遍无效，也不能将困难样本直接解释为错标、疾病亚型或单一图像质量问题。

## 评价原则

- 使用连续分数计算 AUROC，同时检查 AP，避免只观察阈值分类准确率。
- 比较同一组图像上的候选，并使用图像级配对重采样评估不确定性。正负配对共享图像，不能当成彼此独立的样本。
- 明确训练、统计拟合、开发诊断和最终评价的边界；重复使用的开发集合应如实标明。
- 融合可能修复旧错误，也可能新增错误；方向互补并不直接等于整体 AUROC 增益。
- 中途观察结果后选轮次或选系数，会改变证据的解释。固定预算和固定末轮有助于建立清楚的对照。

## 留下的教训

保留完整实验现场容易积累大量难以理解的模型、缓存和上传包。更有长期价值的记录是：研究问题、固定协议、数据角色、最终比较、局限以及可追溯的依据。
